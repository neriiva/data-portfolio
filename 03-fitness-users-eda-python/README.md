# Fitness club users: EDA and segmentation (Python)

Training case project based on a fitness club dataset.

## Tasks
1. Exploratory data analysis of the users table: data types, missing
   values, outliers in age (IQR method), age distribution.
2. Share of female users by city (groupby, pivot_table, bar chart).
3. Segmentation of users into low, medium and high activity groups
   by average monthly workouts.

## Tools
Python (Pandas, NumPy, Matplotlib, Seaborn)

## Files
- fitness-users-eda.ipynb: notebook with code, results and charts
