# Cohort loyalty and K-factor analysis (SQL)

Training case project based on a mobile game dataset.

## Tasks
1. Hypothesis check: compare the average length of game sessions
   (sessions longer than 5 minutes only) for players acquired in
   November-December 2022 through a new, more targeted advertising strategy
   against all other cohorts.
2. K-factor: calculate the virality of the game and forecast the expected
   size of a future average monthly cohort.

## Tools
SQL (PostgreSQL)

## Files
- queries.sql: SQL queries for both tasks
